lumen-kv

A from-scratch LSM key-value store in TypeScript. Memtable → WAL → SSTables → size-tiered compaction, with Bloom-filtered reads — built to feel write amplification the hard way, no LevelDB bindings.

View on GitHub README

WAL + memtable

Writes append to a WAL and land in an in-memory memtable before flushing to immutable SSTs.

Size-tiered compaction

When a level hits the threshold, merge into the next level and drop tombstones deeper down.

Bloom reads

Kirsch–Mitzenmacher Bloom filters keep point lookups cheap without false negatives.

How to run

npm install && npm test && npm run build
npm run cli -- put demo hello world
npm run cli -- get demo hello
